# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) for the personal website repository. ADRs capture significant architectural decisions, trade-offs, rationale, and explicit operational directives for human engineers and autonomous AI agents.

## ADR Lifecycle & Governance

- **Accepted:** Decisions that are currently active, enforced, and adopted across the repository.
- **Proposed:** Forward-looking strategic shifts, tech migrations, or structural proposals undergoing trade-off review before implementation.
- **Superseded:** Decisions that have been replaced by a newer ADR (must link to the replacement ADR).
- **Deprecated:** Decisions that are phased out without a direct replacement.
