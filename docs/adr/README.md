## Governance & Rules

- **Sequential Numbering:** ADRs must follow strictly incrementing four-digit numbers (`0001`, `0002`, `0003`, etc.).
- **AI Directives:** Every ADR must contain an explicit `Directives for AI Agents` section with actionable `Do` and `Don't` guidelines.
- **Immutability:** Established ADRs must not be deleted or silently overwritten. Deprecations or replacements require linking to a new ADR.
