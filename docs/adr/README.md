## Governance & Guidelines

- **Status Lifecycle:** `Proposed` → `Accepted` → `Superseded` / `Deprecated`.
- **Sequential Numbering:** ADRs must be numbered strictly sequentially (`0001`, `0002`, `0003`, etc.).
- **AI Agent Directives:** Every ADR MUST include an explicit "Directives for AI Agents" section with actionable "Do" and "Don't" rules to prevent AI agent drift.
