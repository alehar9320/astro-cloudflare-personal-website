## Governance Process

- **Accepted Decisions:** Represent active, enforced codebase conventions and architectural choices.
- **Proposed Decisions:** Represent forward-looking structural shifts or strategic migrations undergoing review.
- **Superseded / Deprecated Decisions:** Retained for historical context with explicit references to replacement ADRs.
- **Directives for AI Agents:** Every ADR includes mandatory `Do` and `Don't` directives that govern autonomous AI agents operating on this repository.
