## Governance Process

Architectural decisions are governed by **Archie** (Autonomous Chief Architect).

- Established patterns and decisions are recorded as `Accepted`.
- Proposed architectural evolutions are recorded as `Proposed`.
- All ADRs include explicit **Directives for AI Agents** to maintain repo consistency and prevent agent drift.
