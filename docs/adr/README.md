## ADR Lifecycle & Rules

- **Accepted**: Active architectural pattern or established decision in current production/development use.
- **Proposed**: Strategic evolution, migration, or structural proposal awaiting implementation or evaluation.
- **Superseded**: Replaced by a newer ADR (must explicitly link to the replacement ADR).
- **Deprecated**: Phased out and no longer recommended.
