## ADR Lifecycle

- **Accepted:** Decisions currently active and enforced across the repository.
- **Proposed:** Strategic architectural shifts or tech evolutions awaiting adoption.
- **Superseded:** Replaced by a newer ADR (must link to replacement).
- **Deprecated:** No longer recommended or active in the repository.

## AI Agent Governance

Every ADR contains explicit **Directives for AI Agents** (`Do` and `Don't` rules). Autonomous agents operating in this repository MUST comply with all active ADR directives.
