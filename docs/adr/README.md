## Governance & Process

ADRs are governed by the Autonomous Chief Architect (`Archie`). Every architectural decision record in this directory must:

1. Follow strict sequential numbering (`0001`, `0002`, `0003`, ...).
2. Explicitly specify a status (`Accepted`, `Proposed`, `Superseded`, or `Deprecated`).
3. Include an explicit **Directives for AI Agents** section containing actionable `Do` and `Don't` guidelines to maintain repository boundaries and prevent agent drift.
4. Be indexed in this `README.md` file.
